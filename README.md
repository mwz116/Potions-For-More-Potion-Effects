# Potions For More Potion Effects

Adds potions for the effects from mod **"More Potion Effects"**.

⚠️ **This mod is currently in early development, not yet fully complete, and may contain issues.**

## ⭐Description

This mod is an add-on for mod **"[More Potion Effects](https://www.curseforge.com/minecraft/mc-mods/more-potion-effects)"**.

**It adds many potions with different effects**, all of which originate from the **"More Potion Effects"** mod. These potions feature unique and interesting brewing recipes, greatly enriching the potion-brewing experience.
